# UNIPICK
다중 셀러가 입점하는 쇼핑몰 플랫폼입니다. 구매자, 판매자, 관리자 세 가지 사용자 유형별로 기능을 구현했습니다.

## 프로젝트 개요
- 개발 기간: 2025.03 ~ 2025.04
- 팀 구성: 3명
- 주요 내용: 다중 셀러 입점형 쇼핑몰 플랫폼 (구매자/판매자/관리자 기능 분리)

## 담당 역할 (팀장)
- **구매자**: 상품 상세페이지, 결제, 주문, 스토어 페이지
- **판매자**: 로그인, 입점 가입
- **관리자**: 회원관리(판매자)

## 기술 스택
`Java` `Spring` `JSP` `MyBatis` `MySQL` `HTML` `CSS` `JS` `Bootstrap` `AJAX` `jQuery`

## 배운 점
다중 셀러가 입점하는 복잡한 구조를 설계하며, 기능 간 흐름을 정리하고 팀원들과 소통하는 게 핵심이었습니다. 팀을 이끌고 일정을 조율하는 리더로서의 책임감과 유연한 대처 능력을 키울 수 있었습니다.
